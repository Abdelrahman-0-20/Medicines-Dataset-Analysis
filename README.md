# Medicines-Dataset-Analysis
# Medicine Analysis Report

**Dataset:** [Medicines Dataset](https://www.kaggle.com/datasets/drowsyng/medicines-dataset)  

## Overview
This project analyzes a dataset containing information about various medicines. The data includes multiple records, each representing a specific medicine with attributes such as name, manufacturer, composition, uses, and pricing.

## Key Variables
| Column | Description |
|--------|-------------|
| `Medicine Name` | The commercial or generic name of the drug |
| `Manufacturer` | Company that produces the medicine |
| `Composition` | Active ingredients or chemical formula |
| `Uses` | Medical conditions the medicine treats |
| `Price` | Cost of the medicine (if available) |

## Basic Findings
- The dataset contains a wide range of medicines from different manufacturers.
- Prices vary significantly depending on the type and brand of medicine.
- Missing values were handled using standard cleaning techniques (e.g., dropping incomplete rows or filling with defaults).

## Conclusion
This analysis provides a broad overview of the medicines available in the dataset, highlighting key attributes and laying the groundwork for deeper investigation into pricing trends or common uses.

## Tools
Python (Pandas, Matplotlib)
